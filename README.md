# Wells Fargo Software Engineering Virtual Work Simulation

This repository contains my completed work for **Task 1 and Task 2** of the **Wells Fargo Software Engineering Virtual Work Simulation** on the Forage platform. In this simulation, I assumed the role of a **Project Analyst** on an investment management technology team, contributing to the early design and implementation of a system intended to help financial advisors manage client portfolios more efficiently.

---

## Project Overview

The primary goal of this project was to design and implement a **robust data model** that supports financial advisors, their clients, client portfolios, and associated securities. Emphasis was placed on clean data modeling, relational integrity, and correct use of the Java Persistence API (JPA).

---

## Completed Tasks

### 1. Data Model & Entity Relationship Diagram (ERD)
- Designed a comprehensive **Entity Relationship Diagram (ERD)** based on provided business requirements.
- Identified key entities including **Advisor, Client, Portfolio, and Security**.
- Defined appropriate relationships (one-to-many and one-to-one) to support a relational database.
- Created a visual ERD to guide backend system development.

### 2. Implementing the Data Model with Java (JPA)
- Implemented Java entity classes using **Spring Framework and JPA**.
- Annotated each entity with `@Entity` and configured auto-generated primary keys.
- Defined relationships using annotations such as `@OneToOne` and `@ManyToOne`.
- Added constructors, getters, and setters for all entity attributes.
- Ensured the implementation aligned with the approved ERD and best practices.
